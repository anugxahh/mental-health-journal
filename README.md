Mental Health Journal With Mood Analytics 

Mental Health Journal with Mood Analytics is a web-based application designed to help users track their daily emotions, thoughts, and mental well-being.

The project provides a secure and user-friendly platform where users can:

Write daily journal entries
Track moods over time
View mood statistics using charts
Analyze emotional patterns
Improve self-awareness and mental wellness

This application is developed using HTML,CSS, and JavaScript and it works directly with VS Code Live Server and does not require Node.js, npm, React, or any backend framework.

The external frameworks we used include:
TailWind CSS 
AOS 
Font Awesome 
chart.js
